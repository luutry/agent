## 二、已实施修复

### Tier 1 — P0 正确性（R5）
- **N1 阈值放行**：`DefaultSelfCritiqueService.detectHallucination` 的事实校验分支由"支持比例 ≥ 0.5"改为
  **含数值句子任一未命中即 hard fail（归零）**，杜绝"两条真数据夹一条编造"。无数值元话语句不参与判定。
- **N2 三个互斥"人数"**：`FactExtractor` 增 `NON_BUSINESS_METRICS` 黑名单，`totalEmployees`（明细记录数）
  **移出 FactSet**；`DataTemplateRenderer.METRICS` 同步删除死条目。消除 metric 歧义对校验判别力的稀释。

### Tier 2 — 架构级（复审第 10 节"正确契约"）
- **N5 就近绑定耦合**：`DataTemplateRenderer.render` 返回 `RenderResult(text, usedFactKeys)`，
  渲染时把每个数值**绑定到 factKey（entity#metric）**；`AgentResponse` 承载 `usedFactKeys`；
  `DefaultSelfCritiqueService` 对模板路径改为 **`usedFactKeys ⊆ factSet.keys()` 集合比对，零自然语言解析**。
  LLM 路径仍回退 Tier1 的 `verifyByFacts` 硬校验。一次性消除 value 解析、metric 推断、实体绑定三处不确定性。

### Tier 3 — 健壮性/透明度
- **N3.2 commonPool**：`ToolExecutor` 改用**专用有界线程池**（命名守护线程 + `ArrayBlockingQueue(128)` + `AbortPolicy`），
  `@PreDestroy` 释放；避免 3s 阻塞工具占满 commonPool 拖垮全局并行任务。
- **N4 静默截断**：`TeamMetricsTool` 请求"各部门"但按权限只返回部分时，回传 `scopeNotice`
  （`ToolResult.SCOPE_NOTICE_KEY`，**不含数字**以免干扰数值校验）；`PlannerService` 追加到答案。
- **N7 因果/比较句**：`DataTemplateRenderer` 命中因果/比较/建议词（为什么/最高/对比/建议…）时返回 empty，回退 LLM。
- **N6 period 静默忽略**：命中时间限定词（本月/今年…）时答案追加"（当前快照，不支持按时间筛选）"，
  不静默忽略用户限定（R5 隐性变体）。真 period 槽位下推记入 TODO-011。
- **N9 Mock 口径**：`MockHrDataProvider.initEmployees()` 注明"明细是样本、部门级 headcount/currentStaff 才权威"，
  样本聚合仅演示；数据一致化记入 TODO-011。
